# PF Lab 08 – Pointers

This repository contains my solutions for Lab#08 of the course CL-1002 Programming Fundamentals (FAST-NUCES, Fall 2026), taught by Sir Muhammad Aais Rabbani.

All programs are written in C. Every user-defined function has a prototype above `main` and its definition below `main`. Pointers are used to access and modify variables and return multiple results through pointer parameters.

## Programs Included

1. Pointer Basics – declares integer, float, and character variables and accesses their values and addresses using pointers.
2. Sort Three Numbers – sorts three integers in ascending order using `swap()` and `sortThree()` functions.
3. Circle Calculator – calculates the area and circumference of a circle using pointer parameters.
4. Time Converter – converts total seconds into hours, minutes, and seconds and adds extra seconds using pointers.
5. Bank Account – menu-driven program for balance checking, deposits, and withdrawals using pointers.
6. Quadratic Equation Solver – calculates the real roots of a quadratic equation using pointers and `sqrt()` from `math.h`.

## How to Run

    gcc filename.c -o output -lm
    ./output

(`-lm` is needed only for Question#6, which uses `math.h`.)
